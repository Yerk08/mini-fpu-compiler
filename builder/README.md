# Builder — компилятор выражений в x86 FPU Assembly

Утилита для парсинга математических функций из обратной польской записи (RPN), построения AST, символьного дифференцирования и генерации оптимизированного ассемблерного кода (x86 FPU) в поток стандартного вывода.

## Формат входного файла (`SPEC_FILE`)

Путь к файлу спецификации передается через переменную окружения `SPEC_FILE`. Файл содержит границы отрезка интегрирования и три функции в постфиксной нотации (RPN):

```text
-6.1                        # Начало отрезка (rangeStart)
15.2                        # Конец отрезка (rangeEnd)
2 x 4 / tan -               # f1(x): 2 - tan(x / 4)
x 3 / x 3 / + x 3 / +       # f2(x): x/3 + x/3 + x/3
0.2 pi *                    # f3(x): 0.2 * pi
```

**Поддерживаемые элементы:**
* **Операнды:** числа с плавающей точкой, константа `pi`, переменная `x`.
* **Бинарные операторы:** `+`, `-`, `*`, `/`.
* **Унарные функции:** `sin`, `cos`, `tan`, `ctg`.

## Архитектура и этапы компиляции

1. **Парсинг (`parser.c / .h`)** — чтение файла `SPEC_FILE` и построение исходного AST с помощью стека.
2. **Дифференцирование (`derivs.c / .h`)** — генерация новых AST для первых производных $f'_1(x), f'_2(x), f'_3(x)$.
3. **Оптимизации (`optimizations.c / .h`)**:
   * *Constant propagation* — свертка константных подвыражений.
   * *Reduction* — алгебраическое упрощение дерева (удаление нейтральных элементов и т.д.).
   * *FPU Stack optimization* — перестановка операндов (`isSwapped`) для генерации инструкций `fsubrp` / `fdivrp` и снижения глубины стека x86 FPU.
   * *Square hints* — поиск умножения одинаковых подвыражений (`isDuplicated`) для генерации `fmul st0, st0` без дублирования вычислений.
4. **Кодогенерация и отладка (`generator.c / .h`, `debugging.c / .h`)** — дамп секций констант и ассемблерного кода в `stdout` с автоматическим добавлением комментариев на основе строкового представления AST.

## Сборка и запуск

Компилятор собирается под Unix и Windows с жесткими флагами проверок (`-Wall -Werror -fsanitize=undefined`):

```bash
# Сборка бинарника building
make all

# Запуск с генерацией кода и включенными оптимизациями
SPEC_FILE=test.txt ./building -o -r > ../functions.asm

# Запуск встроенных тестов (включая проверку утечек памяти через valgrind)
make test
```

### Флаги командной строки

* `-t` — вывод отладочного представления AST в виде комментариев.
* `-o` — оптимизация стека FPU и свертка констант.
* `-r` — алгебраическая редукция и упрощение выражений.
