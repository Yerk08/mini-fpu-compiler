## О проекте

Кроссплатформенная (Unix / Windows) утилита для нахождения точек пересечения трех кривых методом Ньютона и вычисления площади ограниченной ими фигуры методом трапеций.

**Ключевая особенность — встроенный транслятор выражений (`builder/`):**
Вместо хардкода функций на ассемблере проект включает собственный мини-компилятор. Он читает математические выражения из файла (`SPEC_FILE`), строит AST, аналитически вычисляет производные (f₁, f₂, f₃ → df₁, df₂, df₃), оптимизирует стек x86 FPU и генерирует готовый файл `functions.asm`.

```text
in.txt (RPN) ──▶ [ builder ] ──▶ functions.asm ──▶ [ NASM + GCC ] ──▶ ./integral
```

## Архитектура проекта

* **`builder/`** — компилятор математических функций из обратной польской записи в x86 Assembly ([подробнее](builder/README.md)).
* **`integral.c / .h`** — точка входа (`main`), парсинг аргументов командной строки.
* **`solution.c / .h`** — логика поиска всех точек пересечения и вычисления итоговой площади фигуры.
* **`calculation.c / .h`** — численные методы: `root()` (метод касательных Ньютона) и `integral()` (метод трапеций).
* **`functions.asm / .h`** — сгенерированные ассемблерные реализации функций `f1..f3`, их производных `df1..df3` и границ отрезка `A, B`.
* **`testing.c / .h`, `testintegral.c / .h`** — встроенный фреймворк модульного тестирования точности вычисления корней и интегралов.

## Сборка и запуск

Для сборки требуются `gcc`, `nasm` и `make`.

```bash
# 1. Генерация ассемблерного кода и сборка основного бинарника
SPEC_FILE=in.txt make all

# 2. Сборка отдельного бинарника и тестирование
SPEC_FILE=in.txt make test
```

### Примеры использования

```bash
# Вывод абсцисс точек пересечения и числа итераций
./integral --root

# Вычисление площади фигуры
./integral --integral

# Запуск встроенных тестов точности (формат F1:F2:A:B:E:R)
./integral --test-root 1:2:0.5:5.0:0.0001:3.85
```
